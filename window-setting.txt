* oh my posh (단독 exe 설치 - 2026-08 변경)
    > (금지) winget install JanDeDobbeleer.OhMyPosh
      → MSIX(스토어 패키지)로 설치되어 exe 스폰이 느려짐 (터미널 로드 ~1500ms,
        재부팅 직후 2000ms+). 단독 exe면 ~576ms.
    > GitHub 릴리스의 단독 exe를 받아 사용자 PATH에 등록:
        $bin = "$env:LOCALAPPDATA\Programs\oh-my-posh\bin"
        New-Item -ItemType Directory -Force $bin | Out-Null
        Invoke-WebRequest 'https://github.com/JanDeDobbeleer/oh-my-posh/releases/latest/download/posh-windows-amd64.exe' -OutFile "$bin\oh-my-posh.exe"
        [Environment]::SetEnvironmentVariable('Path', "$bin;" + [Environment]::GetEnvironmentVariable('Path','User'), 'User')
    > 업데이트: oh-my-posh upgrade   (winget 업데이트 아님)
    > 테마: $PROFILE이 ~/.mytheme.omp.json 을 자동 로드 (원본은 omp-mytheme 폴더)
    > 현재 테마 내보내기: Export-PoshTheme -FilePath ~/.mytheme.omp.json -Format json
